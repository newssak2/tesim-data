# 테심이 카메라 목록

안드로이드 앱 **테심이**(과속·구간단속 알림)가 받아가는 카메라 목록이다.
앱이 일주일에 한 번 여기를 보고 새 목록이 있으면 받아간다.

출처는 공공데이터포털의 [전국무인교통단속카메라표준데이터](https://www.data.go.kr/data/15028200/standard.do)
이며, 그중 과속 단속에 해당하는 것만 골라 정리한 것이다.

## 파일 형식

`cameras.tsv` — 탭으로 구분, 첫 줄은 열 이름

| 열 | 뜻 |
|---|---|
| `lat` / `lon` | 위도 / 경도 |
| `limit` | 제한속도(km/h) |
| `kind` | `F` 고정식 과속 · `S` 구간단속 시점 · `E` 구간단속 종점 |
| `dir` | 도로노선방향 코드 |
| `road` | 도로노선명 |
| `place` | 설치장소 |

## 갱신

원본이 반기마다 갱신된다. 만드는 방법은 앱 저장소의 `camera-data/publish.md` 참고.

이 저장소가 **공개**인 이유는 앱이 로그인 없이 받아가야 하기 때문이다.
공공데이터 좌표만 담고 있어 개인정보는 들어 있지 않다.
